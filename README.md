# Flower Snatcher
#### In this Python script you can see the color circle that appears in the middle of the window and you have to press the `space` key on your keyboard fastest as you can and win. This game is multiplayer and you can not play it single. This code is in progress and you can play it now, but you won't enjoy it because it isn't exciting yet.

***

### GUI interface preview:

When you start the code there will appears pop-up window using `askstring` command to ask you for a players nickname.

<img width="1470" height="873" alt="Picture 2" src="https://github.com/user-attachments/assets/d726d7bd-7ed0-409a-8bde-66a8f3637ca2" />

After that there will be a big window. On this window is green background symbolizing grass and a yellow circle symbolizing flower. You have to press the `space` key on your keyboard to snatch the flower fastest as you can and wait until the flower reappears. The entire cycle repeats itself. A multiplayer mode will soon be available, in which one player will be assigned, for example, the `S` key and the other player the `K` key, and they will try to steal the flower before their opponent does. During the game, points for each stolen flower will be assigned to the nickname associated with that key, and the winner will be displayed at the end of the game.
